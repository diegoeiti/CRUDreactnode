
# 🚀 CRUD Fullstack - React + Node.js + MySQL

Sistema completo de cadastro de usuários com operações CRUD.

---

## 📦 Tecnologias

- **Frontend:** React, Styled Components, Axios  
- **Backend:** Node.js, Express, MySQL  
- **Deploy:** Render (Backend) + Vercel (Frontend)

---

## ⚙️ Instalação

### 🔹 Backend

```bash
cd api
npm install
npm start
```

### 🔹 Frontend

```bash
cd frontend
npm install
npm start
```

---

## ✨ Funcionalidades

✅ Criar usuários  
✅ Listar usuários  
✅ Editar usuários  
✅ Deletar usuários
